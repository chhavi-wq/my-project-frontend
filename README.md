Sage Ecommerce App

A full-stack e-commerce web application where users can browse products, add items to the cart, and complete secure payments using Razorpay. Features include email OTP authentication, order management, and a responsive UI.

 Live Demo
- Frontend: https://my-project-frontend-9ukq.vercel.app/
- Backend API: https://my-project-backendd.onrender.com

The backend is hosted on Render's free tier, so the first request may take 30-60 seconds to wake up. Please be patient.

Demo Credentials
Email OTP is sent using Resend in testing mode, which only delivers emails to the account owner's address. So OTPs will not reach new emails. Please use this pre-created account to log in:

| Field    | Value                |
|----------|----------------------|
| Email    | admin@gmail.com    |
| Password | 123                |


 Payment Testing (Razorpay Test Mode)
Payments run in test mode, so no real money is charged. Use these details:

Test Card
- Card number: `5267 3181 8797 5449`
- Expiry: any future date (e.g. `12/30`)
- CVV: any 3 digits (e.g. `123`)
- OTP (if asked): `123456` or choose "Success" on the test bank page

Test UPI
- UPI ID: `success@razorpay` (payment succeeds)
- UPI ID: `failure@razorpay` (payment fails, for testing failure)

 Tech Stack
- Frontend: React, deployed on Vercel
- Backend: Node/Express etc., deployed on Render
- Email: Resend
- Payments: Razorpay
